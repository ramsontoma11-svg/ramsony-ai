RAMSONY AI® — STARTER APP

WHAT THIS STARTER DOES
- Installs as a home-screen web app (PWA) when hosted on an HTTPS website.
- Caches the app shell for offline opening.
- Saves notebook entries locally in this browser/device.
- Offers voice dictation where the browser supports SpeechRecognition.
- Provides a starter interface for future AI, music, image and video integrations.

IMPORTANT LIMITATIONS
- The Send request button is a placeholder. It does NOT connect to an AI model yet.
- Full AI replies require a secure server/backend and an AI provider connection.
- Do not put private API keys in index.html or other browser files.
- Local notes are stored in this browser's local storage. Clearing browser data can erase them; export backups regularly.
- Voice dictation support varies by browser and may require internet and microphone permission.
- Offline mode currently covers opening the app shell and using the local notebook; it does not provide offline generative AI.

HOW TO INSTALL ON ANDROID
1. Host these files on an HTTPS website (for example, a hosting service).
2. Open that HTTPS address in Chrome on your Android phone.
3. Open Chrome's menu (three dots) and choose "Add to Home screen" or "Install app".
4. Confirm. RAMSONY AI will appear as an icon.
