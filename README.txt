RAMSONY AI® — Creative Studio v2

Included:
- Black/electric-blue responsive website interface
- Voice dictation where browser support exists
- Music lyrics/style workspace and local audio-file preview
- Video upload preview and creative brief
- Two-photo upload with local slideshow transition preview
- Image prompt builder
- Local notebook and song draft storage
- PWA manifest and offline app-shell cache

Important limitations:
This is a front-end starter. It does NOT yet connect to an AI chat model, music generator, image generator, or AI video generator. The two-photo feature currently previews a slideshow transition; it does not create AI motion or export a finished video. Uploaded media is previewed locally in the browser. Notes are stored in local browser storage and are not synced or password protected.

Security:
Never put API keys, passwords, private notes, or secret tokens in this public GitHub repository. Real AI services must be connected through a secure backend with suitable privacy and safety controls.

To update GitHub:
Upload/replace the files in the repository root with these files, then commit the changes. GitHub Pages should redeploy automatically.
